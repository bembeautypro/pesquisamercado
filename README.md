# Defesa - Ação Renovatória
## Rua Ferreira Borges, 42 | Campo Grande - RJ

Site interativo com análise completa da defesa na ação renovatória.

### Características
- Análise crítica do laudo pericial
- Pesquisa de mercado com 8 imóveis
- Gráfico comparativo de preços
- Mapa interativo com localização dos imóveis
- Design mobile-first e responsivo

### Deploy
Hospedado em Vercel: https://amendola.app.br
